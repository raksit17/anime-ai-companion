# แนะนำกิจกรรมถัดไป

พิมพ์ “แนะนำกิจกรรมต่อไป”, “วันนี้ทำอะไรดี” หรือ “แนะนำอะไรเบา ๆ” ในแผนชีวิต

- อ่านตารางจริงในธุรกรรมเดียวกับการบันทึกข้อความ ไม่ต้องรอโมเดลหรือ GPU
- “วันนี้/ตอนนี้/ต่อไป” อ้างเวลาปัจจุบันกรุงเทพ ไม่ใช่วันที่เก่าที่เปิดค้างไว้ ระบุวันที่ YYYY-MM-DD หรือพรุ่งนี้ได้
- ถ้ามีงานในช่วงเวลาปัจจุบัน จะแจ้งตามตารางโดยไม่เดาว่าเริ่มทำจริงแล้ว
- แนะนำงาน planned ถัดไปที่ยังไม่พ้นเวลา ไม่หยิบ done/skipped/deferred หรือกิจกรรมที่ทำสำเร็จวันนี้แล้วมาแนะนำซ้ำ
- เมื่อไม่มีงานถัดไป เลือกจากเป้าหมายตามลำดับความสำคัญ ตรวจวันทำ วันพัก วันที่ระงับ เพดานรายวัน เวลาเข้านอน และพักอย่างน้อย 15 นาที
- หากไม่มีเป้าหมายที่เหมาะสม ใช้เฉพาะงานที่ยืนยันทำสำเร็จในสี่วันก่อนหน้า พร้อมระบุว่าเป็นการทดลองจากประวัติ ยังไม่ใช่นิสัยที่ยืนยันแล้ว
- พลังงานต่ำเสนอช่วงไม่เกิน 20 นาที เมื่อไม่มีข้อมูลหรือเวลาที่เหมาะสมจะแจ้งตรง ๆ และขอความสนใจเพิ่มเติม
- การถามคำแนะนำไม่เปลี่ยนตาราง ปุ่มตัวเลือกส่งคำสั่งเพิ่มงานผ่านตัวตรวจข้อจำกัดเดิมอีกครั้ง ตามโหมดจัดตารางอัตโนมัติของผู้ใช้

ทดสอบ regression สำหรับกรณีในภาพ: หน้าเปิดวันก่อน งานเสร็จแล้ว และเวลาที่ผ่านไป รวมถึงการเลือกงานถัดไป การพัก เพดานพลังงาน และไม่แก้ state ต้นฉบับ
